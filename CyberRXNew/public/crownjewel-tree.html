Illustrative sample data (an insurance carrier, to match the “Claims Processing” example). Crown jewels are applications and key infrastructure (firewalls, identity) — data is protected as a risk to the application or system that holds it, not as a separate crown jewel. Each crown jewel's value is split across its controls; a control at maturity 3 or higher is treated as mitigating its slice (struck through), and live $ at risk sums only the slices guarded by controls below 3 — rolled up jewel → process → function → enterprise.
